## [1.0.0] - 未发布

### 本次变更
- 新增宪法规则 I（输出一句一件事）＋ 专门法「五·补、句子形态」
- 目录架构重组为 12 个通用顶层目录；脚本目录统一为 `scripts/`，口径全包统一
- 脚本升级并剥掉本机专属依赖（write-lock / session-ledger / session-open / lint-wiki / sync-agent-cards）
- 消除 12 类历史遗留问题（权限口径、占位、死引用等）
- 脱敏两道闸门（形状扫描＋阳性对照、干净上下文逐文件通读）＋ `release-check.mjs` 固化
- 补开源要件：LICENSE(MIT) / README / CHANGELOG / package.json / .gitignore / .gitattributes
- 根 README 增英文精简版（`README.en.md`）：核心结构翻译，原则部分精简；中英两版登记为**强依赖**（改中文必须同步英文）
- 包名统一为 `rulevault`；去掉规则正文里的立法日期戳，脚本注释保留部分设计沿革（用于解释设计取舍）
- 删除无调用方的导出与不存在的命令行参数（不留悬空件）
- **框架化定界**：明确「框架规定怎么组织与检查，不规定你要记什么」——据此删去全部内容领域预设（`格式约定` 的日记/财务/健康/日程/习惯/人物/学习/视频/购物九节压成「组织方法」四节；删 `日记`/`读书笔记`/`人物档案` 三个内容模板与 `回顾流程`；删最后一个预置内容页 `资产总览`）
- 删去原库主个人主题残影 24 页与内容领域页（装备库/金句集/想法池/人生进阶指南/资产总览等），文件数 83 → 59（分两批；含 10-记录 领域子目录清理）
- `学习与循证协议` 改通用定位（标题改「评估·自治·输出」，「学习验证」「高效学习」降为可选一节）；`外部协作` 泛化（不再绑定记账/清单/日记类软件）；schema 类型表与各页目录描述同步泛化
- 目录骨架保留（只删页面，不删目录结构）
- **修三个「闸门自己失效」的功能性 bug**（路径基准错位 ⇒ 闸门静默放行）：①`dirtyPaths` 报的是 **git 根相对**路径而非包根相对（整仓布局下闸门判空）②过度防御把「包内零改动」误判成异常并崩溃 ③`git rev-parse HEAD:<路径>` 永远从仓库根解析 ⇒ 删除文件的收尾指纹恒失败
- **归档例外传进所有「AI 开场真会读到」的载体**：宪法写了「归档区内只留最新一份」，但 4 处派生载体（AGENTS 开场卡 / 每轮必守 / 全局卡 / 自足卡）原先都没有 ⇒ 同一铁律两种行为；并修 `sync-must-keep.mjs` 的取法（例外在下一条 bullet 里，按 key 取首句取不到）
- **两档口径对齐**：精简档补上决策规则、验证题规则、归档例外、开场侧边界与提案边界说明；框架版修正章节引用、注释与实现不符、卡片清册漏登记
