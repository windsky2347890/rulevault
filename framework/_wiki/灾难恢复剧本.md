# 灾难恢复剧本

> 空壳：换机／盘坏时的最小恢复步骤。本包零服务依赖，只需 Node 与系统 git。
> 1. 整盘拷贝或 `git clone` 归位；2. 设仓库级占位身份（别动 `--global`）；3. 跑 `node scripts/session-open.mjs` 与 `node scripts/lint-wiki.js` 验真；4. 用支持 `AGENTS.md` 的工具重开目录。
> 附件（PDF／图片）不在 Git 里，需随整盘备份单独带走。
