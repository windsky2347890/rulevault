# 外部软件协作（专门法）

> 从 [[使用手册|宪法]] 拆出（专门法）。本空间与你用的外部软件通过"文件交换"协作——**具体是哪些软件、导什么格式，由你定**。

## 原则：一处记录，一处回顾

- 同一类数据只在一个地方日常记录，避免双份维护。
- 本空间是"分析、备份与回顾层"：接收外部软件导出的数据，负责统计与汇总；**回顾的节奏与内容由你定**（见下）。

## 导入（外部软件 → 本空间）

1. 用户把软件导出的文件（优先 CSV，其次 TXT/MD）放进 `00-收件箱/`；
2. 对 AI 说"导入好了"；
3. AI 解析并按 [[_wiki/格式约定]] 写入对应领域文件，处理完的文件移入 `20-知识/sources/` 或 `90-归档/`。

## AI 产出物的落盘去处

**AI 自己产出的东西不进 `00-收件箱/`。** 收件箱只承担一个职责：**外部软件导出的临时落料区**。

| AI 产出物 | 直接落盘到 |
|---|---|
| 调研报告 / 对比分析 | `20-知识/sources/<主题>/` |
| 项目相关产出（尽调、方案、数据） | `40-项目/<项目名>/` |
| 规则 / 机制类产出（体检、提案） | `_AI/` |

> **为什么**：收件箱的"整理"动作挂在触发词「导入好了」上，而**AI 不会对自己说这句话** → AI 产出物一旦丢进收件箱就**没有出口**（实测：AI 产出物会一直积压在那里，因为没有任何环节会去取它）。

## 导出（本空间 → 外部软件）

- AI 按需生成 CSV 等文件放到 `99-导出/`，供导入到支持导入功能的软件。

## 各领域建议

| 领域 | 策略 |
|---|---|
| 记录类 | 日常用你自己的记录软件；**周期汇总由 AI 按你的格式产出到 `10-记录/<你的领域>/`**（**文件交换只是可选通道，不是唯一路径**；本包不附导出脚本） |
| 其他领域 | 直接在对话里说或粘贴；也可定期从你自己的软件导出。**导出与否按需**，AI 不定时汇总（**不写死"每周导出 CSV"**） |
| 清单/待办 | **以你选定的清单工具为唯一权威源**（**前提是你自己给它配好了命令行或 API 通道**；本包不带任何清单工具适配器，具体命令见该工具文档）；待办页降级为长期/跨月事项与需 AI 主动提醒的大事 |
| 知识 | 直接粘贴或丢文件给 AI 整理，按 Wiki 入库流程处理 |

## 同步仪式

- **清单 / 待办不再走"导出 + 口令"**：选定的清单工具是唯一权威源，只要**你自己**给它配好了命令行或 API 通道，AI 就能直接读写，随时可查，**无需周日仪式**。⚠️ 本包**不提供**任何清单工具适配器；没配通道时退回「你贴原文 → AI 落盘」。
- **回顾的节奏与内容由你定**（本包不预设周／月／年回顾清单）；触发点＝你随口一问，或 AI 在收尾时主动报 —— **不要求你在固定时间摆导出文件**。
- 其余软件**按各自节奏**导出即可，不强制固定日期。
