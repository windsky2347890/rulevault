# 评估·自治·输出协议（专门法）

> 本协议把若干借鉴实践固化为**可执行规则**，共五部分：
> - **对外**：怎么评估一个外部建议/疗法/产品（循证评估）——**通用**；
> - **对内**：怎么确认真学会一个概念/技能（学习验证）——**学习场景的细则，用不到可跳过**；
> - **长自治**：怎么让 AI 长时间干活又可读可接管——**通用**；
> - **可读性**：操作类输出行动优先——**通用**。
> - **句子形态**：所有输出的句子形态——**通用**；
>
> ⚠️ **本协议规定的是「怎么评估、怎么自治、怎么写输出」，不规定「你要学什么」。** 学习只是其中一节的场景，其余四节与你的领域无关。
> 原理与术语见库内 [[20-知识/topics/AI原理笔记|AI 原理笔记]]（条目由你按概念追加）；项目台账见 `20-知识/sources/`（用到再建）；
> 与 [[_wiki/原则]]「调查研究七步」的分工：**七步管"怎么查证外部事实"，本协议管"评估建议 + 确认学会 + 自治与输出"。**
> 宪法依据：[[使用手册]] 规则 H（研究者思维）。

## 一、循证评估协议（对外）

> 触发：要决定是否采纳一个**建议、疗法、保健品、筛查、课程、工具**时。

### 三步法

**第 1 步：判证据等级（只管可不可信）**

| 等级 | 判据 |
|---|---|
| **A** | 有具体数字，来自 RCT 随机对照试验 / 荟萃分析 / 大型队列，能说出效应量（HR/RR/下降%） |
| **B** | 有研究支持但说不出确切数字，或仅小样本、单项"回头比对"研究 |
| **C** | 个人经验或公认做法，无直接文献 |

判定要点：优先一手来源（论文 DOI/PubMed、WHO/CDC/统计局等官方文件）；注意区分"随机分组"与"观察性记录"，后者可能有**混杂**。

**第 2 步：判性价比（只管值不值得做）**

- 证据等级 ≠ 取舍，两根独立轴；
- 成本看三项：**钱、时间、要不要毅力**；收益看量级（大/中/小）；
- 好处大且成本近零＝优先做；证据 A 但代价高＝需掂量；证据 C 但成本为零＝也可能很值。

**第 3 步：按口径分账，不可通约**

- 口径四类：**寿命 / 金钱 / 时间精力 / 人身自由**；
- **不同口径之间不互相折算、不硬排总榜**；
- 群体统计效应 ≠ 个人实际收益（看适用人群，如低钠盐对肾病者有风险）。

### 循证评估的三个"反智商税"判据

1. 疗效要看"**比安慰剂组多好多少**"，而不是"多少人说有效"；
2. 无症状人群警惕"过度筛查"——罕见病在低患病率人群中，阳性多为假阳性，会引发不必要手术；
3. 推理链每一步都要单独验证（"抗氧化→抗衰老→防癌"这种常识链可能整体错误）。

## 二、学习验证协议（对内 · **学习场景的细则，用不到可跳过**）

> 触发：学习任何**新概念、模型、技能**，目标是"AI 退出后仍能独立完成"。

### 四段证据链

**① 无 AI 基线**：在求助/学习前，先独立做一次，记录"能完成什么、在哪停住、信心如何"——暴露真实缺口。

**② 辅助学习**：用可信材料 + AI 脚手架（提问、举例、平行题），但**关键步骤自己做**；记录 AI 做了什么、采纳/拒绝了哪些建议。

**③ 延迟独立复测**：隔 3–7 天，**关闭对话、撤掉提示和答案**，完成相近任务——检验长期保持，戳破"当场懂"的流畅性错觉。

**④ 迁移**：改变至少一个条件（主题/受众/材料/工具/时限）仍能完成——确认抓住了底层结构而非记住原题。

**让证据决定下一步**：继续 / 降档 / 改变量 / 暂停；证据冲突不用平均数掩盖。

### 三类信息分开

- **事实**：能指出来源/日期/样本的直接观察；
- **解释**：你如何理解（可被修正）；
- **待验证假设**：下一次行动中检验的判断。
- 说"尚未确认"比把流畅猜测写成事实更专业。

### 三次对照的判读（防止"假学会"）

| 现象 | 更谨慎的解释 |
|---|---|
| 辅助版 + 独立版都变好 | 脚手架有效，能力可能留下 |
| 辅助版变好、独立版退步 | 成品改善，但关键步骤被**外包**，不算学会 |
| 时间变短、返工错误变多 | 欠了"速度债" |
| 信心变高、准确度不变/下降 | 先校准信心 |

## 三、高效学习的执行细则（**学习场景的细则，用不到可跳过**）

1. **间隔练习**：分散到多时间点 + 自测，比集中突击利于长期保持；
2. **交错练习**：不同题型穿插，比一类练到底更利于辨别题型；
3. 少用"反复重读/划重点"（只制造熟悉感）；**"学习风格匹配教学"无证据**；
4. **对抗过早完成感**：宣布"搞定"前加一道可检查测试（闭卷复述/延迟复测/迁移）；
5. **注意力管理**：区分捕获→选择→完成；用环境设计（时间盒 25–45 分钟、手机放远、工作台只留一个任务）保护"完成"，不依赖意志力；
6. **输入三道门**：相关性 / 可信度 / 可行动性，三关不过先不存。

## 四、长时自治协议

> 触发：把任务交给 AI **长时间、多轮自治**执行时。目标：跑得久，但人随时可读、可接管、可撤销。

1. **每轮重述状态**：当前完成到哪、有哪些未闭合线程、下一步是什么——防止长链信息漂移；
2. **关键节点留 checkpoint**：对应一次 Git 提交（文件即记忆），使任何阶段可回滚；
3. **权限与边界事先写明**：AI 可做/不可做、需要人审批的节点、爆炸半径（沙箱）；
4. **停止/回滚条件**：事先约定什么情况下暂停、失败如何恢复；
5. 自治不等于托管——**关键判断与最终责任留在人**（规则 H）。

## 五、输出可读性规范

> 适用：操作类、步骤类回答。目的：降低启动与追踪成本，行动优先。**不需要任何诊断，对所有人都更省事。**

1. **先给下一步动作**，不把答案埋在铺垫里；
2. **步骤编号**；结尾给**一个**具体 next step；
3. 抑制离题；列表控制条数（默认 ≤5）；
4. 时间估计具体到分钟；去掉无信息的开场白/结尾套话；
5. ⚠️ **边界（关键）：风格利落 ≠ 事实正确。** 这是表达层规范，**绝不替代**第一/二节的循证核查——清楚不等于可信。

## 五·补、句子形态（宪法规则 I 的细则）

> 源：[[使用手册]] 规则 I「输出一句一件事」。宪法只留铁律，判例在此。

1. **L1 一句话只说一件事**——不塞「若干问题／以下几个方面」这种虚数包装。
2. **L2 句子短，一句一行**——一个逗号串到底的句子就该断开。
3. **L3 同一概念全程只叫一个名字**——禁同义词轮换。

- **什么算「一件事」**：一件可独立判断的事实、动作或结论；「若干问题／以下几个方面」这类虚数包装不算。（本条是 L1 的**定义口径**；L1 后半句的「虚数包装」是它的典型反例，两者同向，不作两条独立判据。）
- **边界**：短句不得以牺牲准确与完整为代价——该展开就展开；**引用原文、代码、表格不在本节范围**。
- **冲突裁决**：形态与文体层禁令冲突时以**更严者**为准；本节与本库《原则》§六.4「冲突裁决序」并存——本条只管「形态 vs 文体」这一类，同级规则的其他冲突仍走总纲裁决。
- **与本协议 §五 的分工**：§五 管**操作类输出的行动优先**（先给动作、编号、≤5 条）；本节管**所有输出的句子形态**。

## 六、AI 在本协议中的角色

- 讲解顺序：**先专业严谨、后通俗类比，并点明类比边界**（见 AGENTS.md）；
- AI 提供脚手架与多源反馈，但**事实核验、最终判断、关键产出留在人**（规则 H + 人做决策）；
- 状态文件/笔记中不写密码、证件、隐私与未授权第三方信息。
