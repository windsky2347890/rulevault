## 四、清单：剔了什么、为什么

| 剔除项 | 原因 |
|---|---|
| **原库的 `.git`（整个版本历史）** | 原库 git 历史里有隐私数据。文件本身已移出，只有历史里有 ⇒ **原库历史整段丢弃**；本包重新 `git init`，只留一次初始提交 |
| `_wiki/全库索引.md`、`_wiki/归档索引.md`、`_wiki/log.md` | 原页会**把归档文件名原样照抄**（原库的归档文件名里含个人信息形状的串），故**整页换成空壳**，只留格式说明 |
| `_wiki/index.md`、`_wiki/MOC-*.md` | 含原库私人条目 |
| `10-记录/`、`20-知识/sources/`、`30-自我/`、`40-项目/` 的**全部真实内容** | 私人记录 |
| `_AI/` 的真实条目（会话日志 / 踩坑录 / 账本（原文体积很大）） | 私人记录；**只留空壳 + 格式说明** |
| `50-工具/能力清单.md`（原文很长） | 原库主的工具清单；**换成空壳** |
| 大量原库专用脚本 | 是原库主项目的产物（采集、格式转换等工具链），与框架无关 |
| 根目录 `_tmp_*`、`stats.pdf`、`node_modules/`、`.obsidian/` | 临时文件与本地环境 |
| **内容领域页面**（日记/财务/健康/日程/习惯/人物/学习/视频/购物等格式约定与模板、回顾流程、资产总览） | **框架规定「怎么组织与检查」，不规定「你要记什么」**——领域与格式由使用者定，故只留目录骨架与方法 |
| 个人主题残影（装备库/金句集/想法池/人生进阶指南等 20 余个空壳） | 是原库主的兴趣与生活，不是框架的一部分 |
