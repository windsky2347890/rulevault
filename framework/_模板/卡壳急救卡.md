# 卡壳急救卡（策略思维四连问）

> 来源：由「策略思维三问」的原始素材升级而来（AI 补丁：分类 → 诊断 → 归因 → 行动）。
> 用法：学习/工作/情绪卡壳时，照单问一遍。
> 触发器：卡壳超 15 分钟、或情绪触发时——用触发器，不用"频率"（自问太频繁会变成自我监控的焦虑）。

## 四连问

1. **分类**：我现在是哪种状态——困住、没进展、还是沮丧？
2. **诊断**：卡在哪个具体环节？（不是整座山，是一个点）
3. **归因**：是方法问题，还是方向问题？（方向错了，"更好的方法"只是加速撞墙）
4. **行动**：我做什么能帮自己？（如果答案是"累了"——先去休息，这也是答案）

## 原版三问（供对照）

- 困住了 → "我做什么能帮助自己？"
- 没进展 → "还有没有更好的方法？"
- 沮丧 → "我怎么做才能做得更好？"

原版全押在"怎么办"上，缺诊断与归因——本卡补全。

## 原理

- **提问 = 给大脑下搜索词**：问"我做什么"，大脑搜行动选项；问"我好惨"，大脑搜惨的证据。
- 沮丧时的关键判断：**累了**（该休息，不是"做得更好"）vs **没路了**（该换路）。
- 对"过去本可控"的事放过自己；对"此刻仍可控"的事行动。
