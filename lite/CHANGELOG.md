# 变更记录

> **版本口径**：本档版本独立于框架版（`framework/package.json` 记 v1.0.0）——轻量档有自己的节奏，不随框架版跳号。

- 版本号理由：本档 v0.3.0 仍标 0.x（**尚未被真实长期使用**）；框架版 v1.0.0 是「完整治理体系」的定位。两者版本号独立、理由不同，并非疏漏。

## v0.3.0（未发布）

- **与框架版同步「框架 vs 内容」判据**：本页只规定「怎么组织与落盘」，**不规定你要记哪些领域**
- 补入决策规则（对应框架版规则 D）：花钱 / 不可逆 / 有前例的决策先查 `10-记录/<你的领域>/` 下的决策记录（用到再建），与框架版口径一致
- 指路表改为「通用类别」结构（自我 / 记录 / 知识 / 收件箱 / 项目 / 归档）；**领域由他定**——第一次开场问清楚他记哪几类东西，再按他的词建目录
- §四 落盘表、§七 规则分层、§十 目录约定里的具体领域描述（日记 / 财务 / 健康 / 日程 / 习惯 / 决策）改为泛化写法
- 新增「**别替他预设**」：他不记日记就别建日记目录，空目录是噪音
- 升级说明里的模板举例同步框架版（记录与阅读模板已并入通用流程骨架）
