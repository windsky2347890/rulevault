# rulevault · 轻量版

## 这是什么

一套**最小可用**的 AI 知识库骨架：**7 个文件**（开场卡 / 说明书 / 设计说明 / 许可 / 体检脚本 / 变更记录 / 忽略规则，全部约 28 KB）。

**版本** `v0.3.0`（未发布） · **许可** [MIT](LICENSE) · **设计取舍见 [DESIGN.md](DESIGN.md)**（为什么只有 5 项检查、为什么不给写锁）· 规则体系脱胎于个人知识库实践，**本包已彻底脱敏**。

它**不预设任何东西**——你的 AI 会在第一次开场时**主动问你几个问题**，然后自己把目录和文件建起来。

## 怎么用（就 3 步）

1. **用任何会读 `AGENTS.md` 的工具打开这个文件夹**
2. **对 AI 说一句**：「开始吧」
3. **回答它问你的那几个问题**（一次答完就行）

完事。

它会把你的答案写进 `30-自我/速览.md`；以后每次新会话，它都会先读那一页，**不用你再自我介绍一遍**。

## 你会看到什么

- AI **主动**问你 5 个问题（称呼 / 身份 / 角色 / 主要用途 / 要留意的事）
- 答完，它写一个 `30-自我/速览.md`
- 然后你就能正常用了：记东西、问问题、让它帮你整理

**它不会一上来建一堆空文件夹**——用到哪个建哪个。

## 如果它没有主动问你

说明它没读到 `AGENTS.md`。**把 `AGENTS.md` 的内容整个复制粘给它一次**，再让它照做。

## 需要装什么

**Node.js**（只为了跑体检）→ 去 https://nodejs.org 装 **LTS 版**就行。

装完，在这个文件夹里执行：

```
node scripts/check.mjs
```

**没装也能用**——只是少一个"体检"功能，其他一切照常。

## 体检查什么

`node scripts/check.mjs` 查 5 件事：

1. **断链** —— `[[双链]]` 指向了不存在的页面
2. **frontmatter** —— 笔记开头缺 `---` 块，或块里缺 `type`
3. **空文件** —— 建了却一直没写
4. **临时文件残留** —— `_tmp*` / `*.bak` / `~$*` / `*.tmp`
5. **孤立页** —— 没有任何页面链到它

全绿会输出「✅ 全绿」；有问题会逐条列出。**都不是致命错误**，挑你想修的改就行。

**什么时候跑**：觉得"库有点乱了"就跑一次。不用天天跑。

## 已知边界

- **已带一个干净的初始提交**（仓库级占位身份）；push 由你自己点
- **没有并发写锁 / 变更账本** → 那是"多个会话同时改同一个文件"才需要的，一个人用不上
- **规则 11 节** → ①第一件事（含「认人」段）②开场三步 ③铁律 8 条 ④落盘时机 ⑤指路表 ⑥干活做法 ⑦规则分层 ⑧换工具 ⑨怎么改规则 ⑩目录约定 ⑪速览模板

**最重要的**：这套东西**故意很小**。它是起点，不是成品。用久了你会自然想加规则——**加了就写进 `AGENTS.md`**，它就是这样长起来的。
